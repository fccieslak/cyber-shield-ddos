# Exploração

Tentativas de analisar e visualizar o CIC-DDoS2019 na etapa de análise exploratória. Não são o resultado do projeto. Os dados ficam fora do repositório, em `~/ddos-dados`.

| Script | Tentativa |
|---|---|
| `gerador_fluxos.py` | Tabela de fluxos com filtros e distribuição de atributos |
| `mapa_fluxos.py` | Mapa 2D dos fluxos e importância dos atributos em um Random Forest |
| `painel_ddos.py` | Linha do tempo por tipo de tráfego, portas, IPs e acerto de um Random Forest |
| `assinaturas_cic.py` | Um cartão por tipo de tráfego, com mini-grafo |
| `painel_grafos.py` | Fluxos convertidos em grafos, uma estrutura por tipo, com verificação da conversão |
